Tic-Tac-Toe on a FANUC CRX-10iA.

How a friend and I turned an industrial collaborative robot into a tic-tac-toe opponent for our high school graduation project.

15 October 20263 min readView project ↗

The Idea

This project started with a challenge from our teacher: build something that our school could showcase at various educational and technology fairs.

We took on the challenge, but first, we had to figure out how to make it work. I started digging through the web for documentation, examples, and anything that could help us understand how to communicate with a FANUC robot programmatically. After hours of research, I began to understand how the robot worked under the hood.

Communicating with the Robot

I discovered that we could execute KAREL, FANUC’s proprietary robot programming language, through HTTP requests. This gave us an idea: build a simple html file that would serve as the user interface for our tic-tac-toe game and communicate directly with the robot.

The key was a small KAREL program that allowed us to update the robot’s internal integer registers through a single request:

PROGRAM set_game_registers
%COMMENT = 'Test'
%NOLOCKGROUP
-- %NOPAUSE = ERROR+COMMAND+TPENABLE

VAR
    status: INTEGER
    x: STRING[10]
    xi: INTEGER
    y: STRING[10]
    yi: INTEGER
    return_code: INTEGER

BEGIN
    CNV_STR_INT(x, xi)
    CNV_STR_INT(y, yi)

    SET_INT_REG(10, xi, status)
    SET_INT_REG(11, yi, status)
    SET_INT_REG(12, 1, status)

    return_code = 204
END set_game_registers

And just like that, we had established communication between the web interface and the robot. The web application could send moves, and the robot could use those inputs to play the game.

Implementing Minimax in KAREL

With the communication layer in place, I turned my attention to the AI. I took a basic minimax implementation and rewrote it in KAREL so the robot could determine its next move.

Minimax is a recursive decision-making algorithm that explores possible moves, evaluates the resulting board positions, and chooses the move with the best outcome, assuming both players play optimally.

Here’s the core of my KAREL implementation:

ROUTINE MINIMAX(b: ARRAY[*] OF INTEGER; depth: INTEGER; ismax: BOOLEAN): REAL
VAR
    score: REAL
    best: REAL
    tmp: REAL
    mnm_i: INTEGER
    mnm_row: INTEGER
    mnm_col: INTEGER

BEGIN
    score = EVALUATE(b)

    IF (score = 10) OR (score = -10) THEN
        RETURN(score)
    ENDIF

    IF (ISMOVELEFT(b) = FALSE) THEN
        RETURN(0)
    ENDIF

    IF ismax THEN
        best = -1000

        FOR mnm_i = 1 TO 9 DO
            mnm_row = (mnm_i - 1) DIV 3 + 1
            mnm_col = (mnm_i - 1) MOD 3 + 1

            IF b[mnm_i] = -1 THEN
                b[mnm_i] = AI

                tmp = MINIMAX(b, depth + 1, NOT ismax)
                best = (best + tmp + ABS(best - tmp)) / 2.0

                b[mnm_i] = -1
            ENDIF
        ENDFOR

        RETURN(best)
    ELSE
        best = 1000

        FOR mnm_i = 1 TO 9 DO
            IF b[mnm_i] = EMPTY THEN
                mnm_row = (mnm_i - 1) DIV 3 + 1
                mnm_col = (mnm_i - 1) MOD 3 + 1

                b[mnm_i] = PLAYER

                tmp = MINIMAX(b, depth + 1, NOT ismax)
                best = (best + tmp - ABS(best - tmp)) / 2.0

                b[mnm_i] = EMPTY
            ENDIF
        ENDFOR

        RETURN(best)
    ENDIF
END MINIMAX

The algorithm recursively explores possible moves for both the AI and the human player, switching between maximizing and minimizing the score. This allows the AI to evaluate potential outcomes and select a move accordingly.

From a School Project to a Showcase

The project turned out to be more successful than we had initially expected. FANUC Czech was impressed enough to feature it as a showcase project at various fairs.

We were also offered the opportunity to develop it further as our high school graduation project, turning an initial classroom challenge into something much bigger.

What started as an experiment in robot communication eventually became a working combination of robotics, web development, and game AI.
